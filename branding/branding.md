# Core Idea

NextBit is an AI-powered software architecture visualizer.

It helps users understand project architecture by transforming software structures into an interactive city that can be explored.

Instead of reading folders and diagrams, users walk through their software before they build it.

---

# Mission

Software architecture should feel exciting instead of intimidating.

Beginners should be able to understand how a software project is organized without reading long folder trees or boring UML diagrams.

NextBit turns software architecture into something visual, playful, and memorable.

---

# Vision

Every software project begins as an idea.

NextBit gives that idea a city before it becomes code.

---

# Logo

The logo represents software becoming a city.

Typography itself forms architecture.

Concept

NBit

The N and B share a common vertical stroke.

The i is a small building.

The dot is a pixelated sun.

The t is the tallest building and resembles a construction crane, symbolizing that every project is still being built.

Everything should be pixel styled.

---

# Animation Philosophy
